FAQ

Questions before you join

Do I need coding experience?

Not for AI Powered Manual Testing, which needs no coding. The Playwright courses teach you TypeScript or Python as part of building the framework, and students with zero coding background have completed them.

Which course should I choose?

New to QA: start with AI Powered Manual Testing. Comfortable with JavaScript or want the most common Playwright stack: choose TypeScript. Prefer Python or want to test chatbots: choose Python & ChatBot. Still unsure? Message us on WhatsApp.

When are the classes?

Weekday batches designed for working professionals. The next batch runs 7:30–8:30 AM IST, which is 9:00–10:00 PM EST and 3:00–4:00 AM BST.

How much do the courses cost?

The Playwright courses (TypeScript, or Python & ChatBot) are ₹7,900 / $95. AI Powered Manual Testing is ₹5,000 / $60.

Do you help with interviews?

Yes. Students get mock interviews and resume feedback so they can apply for QA roles with confidence.
