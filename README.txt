STEP 1 - EDIT SETTINGS (in index.html, near the bottom, "EDIT THESE")
----------------------------------------------------------------------
WHATSAPP_NUMBER      Country code + number, digits only, e.g. 919876543210
BATCH_START          Next batch start, e.g. 2026-11-05T07:30:00+05:30
BATCH_DATE_TEXT      Date shown for India/UK, e.g. 5th Nov
BATCH_DATE_TEXT_US   Date shown for USA (the evening before), e.g. 4th Nov


STEP 2 - UPLOAD TO GITHUB
-------------------------
1. Open github.com -> repository "Sri_QA_Playwright_Typescript".
2. (Backup) Copy your current index.html into a new file "index-old.html".
3. Add file -> Upload files -> drag in index.html (and images only if missing).
4. Click "Commit changes".
5. Wait 1-2 minutes, open your site, press Ctrl + F5.


TEST LOCALLY FIRST (optional)
-----------------------------
Unzip this folder and double-click index.html - it opens in your browser
with all images working.
